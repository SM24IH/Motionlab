# GRIME × Last Mile — Scope Rewrite
## $30k Build Now vs Full Commerce Engine

**Commercial frame**
- **Build Now (Phase 1):** $30,000 one-time — two live storefronts, launch-ready, deliberately scoped
- **Full Build (Phase 1 Expanded):** priced separately — everything in the original deck ambition
- **Grow (Phase 2):** $7,500 / month retainer — maintenance, CRO, Amazon ops, paid deployment

Last Mile remains the commerce and growth partner — not the creative agency. GRIME supplies approved brand identity, photography, video, UGC, claims/legal, and product data.

---

## OPTION A — BUILD NOW · $30,000

**Promise:** Shopify + Amazon live under one brand system. Fast, connected, enough to sell and learn — not every integration or future channel.

### Shopify (included)

- Custom Shopify Online Store 2.0 storefront (GRIME visual system applied end-to-end — not a generic theme left as-is)
- Parent-first buying journey: homepage, collections, PDPs, cart, checkout readiness
- Modular homepage sections for drops / seasonal campaigns (editor-managed, not fully bespoke campaign tooling)
- Core pages: Home, Shop/Collections, PDP template(s), About / brand story, GRIME 101 or FAQ, Contact, policy pages
- Product architecture for the agreed launch catalogue (SKUs/variants as provided by GRIME)
- Basic bundles or “shop the routine” via native Shopify or lightweight app config (not custom bundle engine)
- Search: Shopify native or standard search app setup
- Mobile-first QA, basic SEO foundations (titles, meta, sitemap, speed pass), privacy/cookie baseline
- Email/SMS **connection only** (Klaviyo or equivalent) — flows/templates owned by GRIME or their CRM partner
- Launch checklist + handoff training (admin, products, pages, basic merchandising)

### Amazon (included)

- Seller / Brand Registry readiness checklist and channel architecture for launch
- Brand Store: structure + build from GRIME-approved assets (standard modules)
- Launch catalogue: titles, bullets, backend search terms, variation structure for agreed ASINs
- A+ Content / Brand Story for hero ASINs (within Amazon module limits; GRIME supplies creative)
- Launch setup: pricing fields, shipping readiness support, category/browse hygiene as applicable
- Measurement baseline: Brand Analytics access path + reporting template for go-live

### Explicitly out of the $30k Build Now

| Out of scope now | Moves to Full Build or later SOW |
|---|---|
| Shopify Plus–only architecture / Plus migration | Full Build |
| Heavy custom theme engineering (unique interaction systems, SOS-level personalisation) | Full Build |
| Recharge / subscriptions build-out | Full Build or Phase 2 add-on |
| Yotpo loyalty + reviews full implementation | Full Build or Phase 2 add-on |
| Custom gifting flows, advanced UGC galleries | Full Build |
| Intelligent / AI search beyond standard app | Full Build |
| WCAG 2.2 AA full audit + remediation programme | Full Build |
| Multi-language / Markets complexity | Later SOW |
| Target / Target Plus | Phase 3 |
| GRIME app | Phase 5 |
| Creative production (photo, video, UGC, renders) | GRIME |
| Paid media creative | GRIME; Last Mile deploys in retainer |
| Ongoing ads, CRO, catalogue ops | Phase 2 retainer |

### Build Now outcome

**Two live storefronts. One brand. One commercial foundation.** Ready to take demand and generate proof for Grow / Expand.

## OPTION B — FULL BUILD · Phase 1 Expanded

**Promise:** The storefront GRIME lives in — built for weekly drops, subscriptions, loyalty, and accessibility — plus Amazon launched as a true brand twin. Price as a separate quote (recommended **$45k–$75k** depending on catalogue size and Plus).

### Shopify (full)

Everything in Build Now, plus:

- Shopify Plus / Plus-ready architecture where required
- Fully custom storefront system for weekly drops and seasonal activity (deeper modular / campaign system)
- Custom PDP patterns, collections, routines, bundles as a designed merchandising system
- Intelligent search (app or custom config beyond native)
- Subscriptions (e.g. Recharge) — plans, PDP/cart UX, testing
- Yotpo (or equivalent) loyalty + reviews — install, theme integration, launch config
- Gifting + UGC presentation integrated into the storefront
- Email/SMS deeper theme integration (preferenced states, embedded forms, launch QA with CRM)
- SEO programme beyond foundations; privacy hardening
- **WCAG 2.2 AA** pass with documented fixes
- Performance budget + launch QA; architecture notes ready for future Gus / app

### Amazon (full)

Everything in Build Now, plus:

- Broader catalogue / variation complexity
- Expanded A+ / Brand Store depth across the range
- Stronger merchandising + measurement instrumentation at launch
- Launch playbook tied to paid and promo calendar (still creative from GRIME)

### Full Build outcome

**Commerce engine, not just two storefronts** — ready for aggressive Grow retainer work without rebuilding foundations.

## PHASE 2 — GROW · $7,500 / month

Applies after Build Now **or** Full Build. Same retainer either way; Full Build simply yields more to optimise.

### Included

**Shopify**
- Site maintenance and technical support (agreed hours / SLA)
- CRO and merchandising changes within retainer capacity
- Landing pages / offers / launch support for campaigns GRIME creatives
- Analytics, tracking health, monthly performance reporting

**Amazon**
- Listing health and catalogue management for live ASINs
- Search, merchandising, and conversion recommendations
- Content/promo updates using GRIME assets
- Marketplace reporting

**Paid growth**
- Deployment and optimisation across **agreed** platforms (e.g. Amazon Ads, Meta, Google — list locked in SOW)
- Shopify + Amazon treated as one acquisition picture
- Optimised to commercial outcomes, not vanity clicks
- Creative stays with GRIME — Last Mile deploys and learns

### Retainer guardrails (put in the SOW)

- Monthly hour pool or deliverable cap (e.g. maintenance + X tests + Y listing updates)
- Media: client pays ad spend; management included up to an agreed monthly spend ceiling; above that, +% or tier upgrade
- Major new templates, apps, or channel builds = change order
- Target and app remain separate phases

## PHASE 3 / 5 — unchanged (not in $30k)

- **Target:** when online proof exists — separate SOW  
- **App:** when behaviour earns it — separate SOW

## Deck slide copy (drop-in)

### Slide: Two ways to start

**Build Now — $30k**  
Custom GRIME Shopify storefront + Amazon launched from scratch. Core pages, launch catalogue, Brand Store, A+ for hero ASINs. Live fast. Learn fast.

**Full Build — scoped quote**  
Plus-ready / deeper custom system, subscriptions, loyalty, accessibility programme, richer Amazon depth. Build the engine once — then Grow harder.

**Grow — $7,500/mo**  
Maintain, convert, catalogue, and deploy paid across agreed platforms. One partner. One rhythm.

### Slide: Build Now includes / excludes (short)

**Includes:** Shopify OS 2.0 GRIME storefront · launch catalogue · Brand Store · hero A+ · measurement baseline · launch QA  

**Does not include:** Plus-heavy custom systems · Recharge/Yotpo full stack · WCAG AA programme · Target · app · creative production · ongoing ads (that’s Grow)

## Recommendation for the proposal

Lead with **Build Now at $30k** so price and promise match. Offer **Full Build** as the upgrade path (or Phase 1b) once drop cadence, subscriptions, and loyalty are non-negotiable for launch. Keep **$7,500 Grow** identical under both paths.
